# Face Filters Growth Audit

**Live → https://eddieatadapty.github.io/face-filters-flow-rebuild/**

Five ideas to turn more Face Filters users into subscribers, each built into a clickable version of Face Filters's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Show their face in the trend before any price | +10–20% CR to purchase |
| 02 | Make yearly the obvious, honest choice | +10–15% ARPU |
| 03 | Catch the people who close the paywall | +10–15% ARPU |
| 04 | Ask which trend they came for, and use it everywhere | +8–15% CR to purchase |
| 05 | Put your 4.4 stars where they wait | +5–10% CR to purchase |

Every price, rating and feature comes from Face Filters's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Face Filters. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
